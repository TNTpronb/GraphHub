### P14. 学生 PR 详情页 `/student/pr/:prId`（含新建 PR 变体 `prId="new"`）

> `prId="new"` 时：为新建 PR 的提交表单
> `prId` 存在时：查看已有 PR 的状态和审核结果

**变体 A：查看已有 PR**

| 组件 | 说明 |
|------|------|
| **PR 头部** | `<PRStatusBadge>` — 当前状态 |
| **PR 时间轴** | 四条节点：已提交 → AI 审核完成 → 小组长审核 → 教师终审（已完成/进行中） |
| **AI 审核卡片** `<AIReviewCard>` | ★ AI 评分仪表盘、重复度警告（如适用）、AI 修改建议（含"一键应用"按钮） |
| **冲突面板** `<ConflictPanel>` | ★ 如有未解决冲突：逐条展示、两边版本对比、三个解决按钮 |
| **Diff 查看** `<PRDiffViewer>` | md 左右对比 / 统一视图 + 关系变更 + 挂载变更 |
| **审核意见列表** `<ReviewHistory>` | 人工审核逐条评论（小组长 / 教师的意见） |
| **修改重提按钮** | 如被"打回"：点击后回到编辑模式修改，重新提交 |
| **取消 PR 按钮** | 状态为 pending 时可取消 |

**变体 B：新建 PR**

| 组件 | 说明 |
|------|------|
| 变更类型选择 | node_add / node_edit / relation_add / ... |
| 提交说明输入 | 描述本次修改的内容和理由 |
| **冲突检测** | 提交前自动检测，如有冲突 → `<ConflictPanel>` 进入冲突解决流程 |
| Diff 预览 `<PRDiffViewer>` | 提交前预览所有变更 |
| 提交按钮 | 所有冲突解决后激活 |

### 关键跳转链路

| 触发 | 起点 | 终点 | 说明 |
|------|------|------|------|
| 新建课程完成 | P2 Step4 | P3 | 发布后跳转到新课程的图谱管理页 |
| 点击待审核课程卡片 | P1 | P8 | 审核工作台（自动筛选该课程） |
| 点击课程卡片 | P1 | P3 | 教师进入图谱管理 |
| 点击课程卡片 | P10 | P11 | 学生进入图谱浏览 |
| 点击节点配套练习 | P11 详情面板 | P12 | 按该 Note 筛选的练习 |
| 点击 Fork 按钮 | P11 | P13 | 一键复刻到私人空间 |
| 提交 PR | P13 | P14 (new) | 新建 PR 提交表单 |
| 点击 PR 卡片 | P8 | P8 抽屉 | 审核工作台内打开 PR 详情抽屉 |
| 点击 PR 卡片 | P10 | P14 | 学生查看 PR 详情 |
| 审核通过 | P8 抽屉 | — | PR 合入，图谱版本号+1，P3 图谱更新 |
| 审核打回 | P8 抽屉 | — | 学生 P14 状态变为"已打回"，可修改重提 |
| 点击错题关联 Note | P15 | P11 | 跳转到图谱浏览页定位到对应节点 |
